# YaskCode Academy

### Learn · Practice · Build · Share

## What is YaskCode Academy?

YaskCode Academy is an open educational ecosystem for Software Engineering, Artificial Intelligence, cloud computing and computer science. It is designed especially for students, educators and Spanish-speaking communities who want to learn through meaningful technical work.

## Mission

Our central idea is simple: **learn Software Engineering by doing Software Engineering.** We aim to help learners design ethical, innovative and impactful technology solutions through active learning, projects, professional practice and open education.

## The YaskCode Learning Model

Learning is not limited to a final product. A learning experience can move through:

> Problem → Requirement → Issue → Planning → Branch → Implementation → Commit → Tests → Pull Request → Automated Checks → Engineering Review → Improvement → Merge → Documentation → Release → Reflection.

GitHub is part of the learning environment. Automation can validate code; engineering review validates the solution.

## The YaskCode Approach

- **GitHub-Native**
- **Project-Based**
- **Standards-Informed**
- **Evidence-Based**
- **Iterative**
- **Open by Design**

## Current Learning Experiences

The Academy brings together learning paths, educational resources, practical projects, guides and tutorials, and community participation. Current experiences are organized around these formats and evolve through documented work rather than unverified claims of scale or adoption.

## Open Education & Open Source

YaskCode Academy is building the foundations for a mature educational open-source initiative: clear mission, transparent governance, contribution pathways, appropriate licensing and public traceability. Open publication is intentional; academic work is not automatically an open-source contribution.

## Governance

The project is currently in a founding stage led by a Project Lead / Founding Maintainer, with a transparent path toward distributed responsibilities as sustained contributors and maintainers emerge. Read [Governance](../GOVERNANCE.en.md) and its [Spanish authoritative version](../GOVERNANCE.md).

## Contributing

We welcome educational, technical, documentation, translation and accessibility contributions. Please start with [Contributing](../CONTRIBUTING.en.md), then review the [Code of Conduct](../CODE_OF_CONDUCT.md) and [Security Policy](../SECURITY.md).

## Licensing

The Academy uses a dual licensing strategy: code and tools will use MIT or Apache-2.0; original educational materials will use CC BY 4.0 or CC BY-SA 4.0. Each public resource will state its specific license before publication. See [Licensing](../LICENSING.md).

## YaskCode Ecosystem

YaskCode Academy focuses on courses, learning paths, assignments and educational materials. It coordinates with YaskCode Research (research and methodology), YaskCode Laboratory (guided project learning) and YaskCode Community (participation and collaboration), while keeping each area distinct.

## Spanish-first · English-accessible

Spanish is not a translation afterthought; it is part of the Academy's mission. Core educational documentation and governance are maintained in Spanish, with concise English access points for international collaborators and evaluators.
